Namdak Tonpa

namdak.tonpa@groupoid.space

I am an independent researcher and the BDFL author of Groupoid Space, a comprehensive framework exploring higher groupoids, homotopy type theory, and foundational structures in mathematics and programming languages for the BEAM ecosystem. My work bridges logic, category theory, and computational mathematics, with a focus on dependent types, groupoid semantics, and infinity structures.

Primary research interests include: higher groupoids, homotopy type theory, dependent type systems, and the design of novel programming languages inspired by foundational mathematicians.

Languages

I design and develop programming languages targeting the Erlang BEAM virtual machine, deeply inspired by the following foundational figures in logic, type theory, concurrency, and mathematics:

  • Alonzo Church — Lambda calculus and computation
  • Yves Lafont — Interaction nets and linear logic
  • Henk Barendregt — Lambda calculus and type theory
  • Per Martin-Löf — Intuitionistic type theory and dependent types
  • Christine Paulin-Mohring — Tactical Theorem Prover
  • Frank Pfenning — Logical frameworks and dependent types
  • Laurent Schwartz — Distribution theory and functional analysis
  • Anders Mörtberg — Cubical type theory and constructive mathematics
  • Urs Schreiber — Higher category theory, cohesion, and differential geometry in type theory
